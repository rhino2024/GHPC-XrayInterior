# 载具内构透视

Gunner, HEAT, PC! 的 MelonLoader 模组。按游戏自己的 X 光键（默认 `O`），你正在驾驶的这辆车会整台透出来：乘员席、发动机、变速箱、装甲衬层、弹架，不再只有原版那几盒弹药。松手就还原。

## 你会看到什么

原版按 `O` 只亮弹药。原因在游戏自己的那套内构逻辑里：内构件平时一条渲染器都不开，要等赛后回放（AAR）才会被点亮，而战斗里那个「正在回放」的开关永远是关的——于是按下去只有弹药能看见。

这个模组把同一辆车其余的内构件一起点亮，用的是游戏给它们准备的那套高亮材质，也就是你在赛后回放里看到的那种黄透效果。量不在多，在于齐：车组、发动机、变速箱、炮闩、弹药架、舱内装甲衬层都在。

**模组不绑自己的键。** 它认的是游戏自己的 X 光开关：你按 `O`，它跟着亮；你哪天把 X 光改到别的键，模组照样跟着那个键走。按住显示、松手还原，和原版的操作手感一致。

**每一次都会还回去。** 关掉 X 光、换一辆车、退出载具、进入赛后回放、在 MelonLoader 里关掉这个模组、退出游戏——内构件、图层、材质、相机全部逐项还原。回放期间游戏自己会点亮同一批内构件，模组进场就主动让开，不跟它抢。

**不碰物理。** 图层决定来袭炮弹打得到谁，所以身上有活 `Collider` 的件（装甲衬层、发动机这些撑碰撞体的）不搬图层；点亮它们靠的是把图层位喂给游戏那台 X 光叠加相机，关窗时还原掩码。炮塔、火控、AI 一律不碰。

**想看得更真**：把 `KeepOriginalTextures` 打开，内构件就用它们自己的贴图显示，而不是回放那种单色黄。

## 装

1. 先彻底退出游戏。游戏开着的时候 dll 是锁住的，覆盖不了。
2. 把 zip 解压到游戏根目录，就是放着 `GHPC.exe` 的那一层。解压出来应该看到 `Bin\Mods\XrayInterior.dll`。
3. 开一次游戏。MelonLoader 会在 `Bin\UserData\MelonPreferences.cfg` 里写出 `[XrayInterior]` 这一段。

需要 MelonLoader（net35 运行时），下载包里没有它。它不改游戏任何文件，删掉那个 dll 就算卸载。

## 能改的东西

| 名字 | 默认 | 作用 |
| --- | --- | --- |
| Enabled | true | 总开关。关掉后按 X 光键只剩原版能看到的那部分 |
| KeepOriginalTextures | false | 用内构自己的贴图显示，而不是赛后回放那种单色高亮 |
| DebugLog | false | 出问题再开，会写 `Bin\Mods\XrayInterior.debug.log`（点亮了多少件、跳过了哪些、相机画哪些图层） |

## 先说清楚

只在 X 光开着的时候临时改写内构件的可见性、高亮、图层和材质，关窗、换车、回放、卸载时逐项还原；渲染之外的东西不碰。

第一次按下可能要等一下：有些内构件是延迟实例化的，模组会在 X 光开着期间每 0.4 秒补扫一轮，晚到的件下一轮就补上。

## 素材

本模组**不含模型与贴图**：被点亮的内构美术全部是 GHPC 游戏本体自带的资源，运行时由游戏加载，模组不分发任何游戏素材，仓库里只有源码与编译脚本，也没有对任何模型做过重拓扑（retopo）处理。
